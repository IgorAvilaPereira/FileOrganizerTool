# FileOrganizerTool

Script em Python projetado para organizar arquivos em diretórios específicos com base em suas extensões. O código foi inspirado em um artigo do [Medium](https://medium.com/@gamsahamidah95/organize-files-in-folders-using-python-script-49fdd4afc6d5) e é útil para automatizar a organização de arquivos em sistemas locais.

## 🛠️ Funcionalidade

O script identifica arquivos em um diretório especificado e os move para subpastas correspondentes às suas extensões. Por exemplo:

* Arquivos .txt são movidos para uma pasta TextFiles/.

* Arquivos .jpg vão para Images/.

* Arquivos .mp4 são direcionados para Videos/.

Essa organização facilita a gestão de arquivos, especialmente em pastas com grande quantidade de documentos.

## 🔧 Tecnologias utilizadas

* Python: Linguagem de programação utilizada para desenvolver o script.

* Bibliotecas padrão do Python: Como os e shutil, para manipulação de arquivos e diretórios.

## 📁 Estrutura do repositório

* organizer.py: Script principal que executa a organização dos arquivos.

* requirements.txt: Lista de dependências necessárias para o funcionamento do script.

* README.md: Documento que fornece informações sobre o projeto e instruções de uso.

## 🚀 Como utilizar

* Clone o repositório ou baixe os arquivos.

* Instale as dependências listadas em requirements.txt (se houver).

* Execute o script organizer.py no diretório que contém os arquivos a serem organizados.

## ⚠️ Considerações

* Personalização: O script pode ser adaptado para incluir mais tipos de arquivos ou diferentes critérios de organização.

* Segurança: Recomenda-se revisar o código antes de executar, para garantir que ele atenda às suas necessidades e não cause perda de dados.
